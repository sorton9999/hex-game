This is a simple hex game called HexEl.  You use keyboard arrows to move a hex tile located at the bottom of a hex gameboard to a goal at the opposite end of the board.  While moving the tile, the gameboard has obstacles to avoid.  These obstacles consist of immovable hex walls and randomly flashing hex tiles.  Your fastest time and least number of collisions are scored.

There is a difficulty level that can be set to make the game more challenging.

See if you can better your previous high score.
